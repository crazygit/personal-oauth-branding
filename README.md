# Hermes GWS Personal Integration

A personal, non-commercial automation tool that connects a self-hosted home
server to the owner's own Google account (Gmail, Calendar, Drive, Tasks) via
the official Google OAuth2 API, for private use only.

- Type: Desktop / CLI application (single user: the owner)
- Contact: via GitHub (open an issue)
- Privacy policy: [PRIVACY_POLICY.md](PRIVACY_POLICY.md)
