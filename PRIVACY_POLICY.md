# Privacy Policy

Last updated: 2026-11-10

This application ("Hermes GWS Personal Integration") is a personal,
non-commercial automation tool used solely by its owner.

1. **Data accessed**: With the owner's explicit OAuth2 consent, the
   application may read and manage the owner's own Gmail, Google Calendar,
   Google Drive, Contacts, Sheets, Docs and Tasks data.
2. **Data storage**: All data is processed on the owner's own private server
   and is used only to serve the owner. No data is collected, sold, rented,
   shared with, or transferred to any third party.
3. **No analytics / No advertising**: The application contains no tracking,
   analytics, or advertising components.
4. **Data deletion**: Since no data is retained beyond the owner's own
   infrastructure, deleting data on the owner's server removes it entirely.
   The owner may also revoke the application's Google access at any time at
   https://myaccount.google.com/permissions.
5. **Contact**: via GitHub issues on this repository.

This tool is not affiliated with, endorsed by, or supported by Google.
